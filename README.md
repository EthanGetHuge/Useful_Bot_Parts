# Useful_Bot_Parts

<img width="128" height="128" alt="image" src="https://github.com/user-attachments/assets/212e436e-6028-441f-a806-aadf5272e4de" />

I have always wondered why the stats for the Dr. Pepper Bot Parts were booty. This mod adjusts the stats, price, and unlock requirements so that they fit within the 4th tier of creature parts. 

You must have Bot Parts already installed to Spore in order to use this mod.
